Latest Projects

Dish Dash

Dish Dash is a mobile application developed with my team using Flutter
The app provides a collection of digital recipes that help users learn cooking, discover new dishes,
and find inspiration when preparing meals.

Jade Silk

Jade Silk is an Android application developed using Kotlin that brings a couture fashion marketplace experience.
Users can explore exclusive fashion collections and schedule home fitting services
for a more personalized shopping experience. Jade Silk is a solution!

Willify

Willify is a web-based music streaming platform developed using HTML, CSS, JavaScript.
Inspired by platforms like Spotify and SoundCloud, the website allows users to stream music,
discover song recommendations, and create personalized playlists.

Piring Nusantara

Piring Nusantara is an Augmented Reality application developed using Unity.
The app allows users to scan a physical plate with the app's logo to display 3D models of Indonesian cuisine using AR technology.
Users can explore traditional dishes interactively while learning about their ingredients, food composition, and regional origins.

Flokemon

Flokemon is an e-commerce mobile application built using Flutter and Firebase that focuses on selling Pokémon toys.
The app allows users to explore products and receive notifications about sales and new item arrivals.

Pure Plate

Pure Plate is an Android application for ordering healthy food while providing detailed nutritional information.
The app allows users to view ingredients and macro-nutrient compositions before choosing their meals.
The application was developed using Android Studio with Kotlin and uses SQLite for database management.

Intellectra

Intellectra is a mobile e-learning application concept designed for a UI/UX competition. The project focuses on creating a modern and engaging learning experience.
The interface and mockups were designed from scratch using Figma.

Danadira

Danadira is a financial service platform developed during my internship to support digital loan services.
Built using React Native, TypeScript, and Node.js.
The system adopts a microservices-oriented architecture with PostgreSQL, Google BigQuery, Python, and Docker for backend services and data processing.

HotForge — Undergraduate Thesis Project

HotForge is a mobile collection management app that allows users to scan and organize items digitally.
It integrates image recognition using Nyckel and is built with React Native, TypeScript, and Firebase Firestore.
The app also includes social features like posts and comments for community interaction.
